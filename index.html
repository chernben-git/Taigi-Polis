文明從家庭走向城邦，語言是文明的根

六千年前，人類從部落走向城邦，文明並不是靠一份法典突然誕生，而是來自三種力量：共同的信仰（文化）、互助的組織（家族 / 社團）、穩定的公共場域（交易 / 交流）。當這三股力量彼此連結、形成循環，文明便會自然生長。

而這樣的文明，其實是在關係、記憶、組織與場域之中慢慢長出來的。最初是家庭，讓聲音成為語言；接著是家族，讓語言成為可傳承的記憶；再來是社團，讓共同信仰、互助與文化形成可持續的組織力量；最後是友善場域，讓語言進入市場、街道、店家與公共生活，成為文明運作的一部分。

當家庭 / 家族 / 社團 / 友善場域這些力量彼此連結、形成循環，語言就不只是被保存，而會重新長成文明。今天，我們用同樣的生成邏輯，重建一套可治理、可擴張、可自我演算增殖的「台語再生循環」。

四層生成力量：台語城邦形成的基礎

① 家庭｜語言誕生的起點

文明從最小的生活單位開始。家庭是語言第一次被說出、被模仿、被理解的地方，也是台語重新回到日常生活的起點。

  • 每日台語生活句、親子共學、日常互動
  • 家庭打卡：連續日數、榮譽牆、成就徽章
  • 把學習從課堂拉回餐桌、客廳與生活
去做「我是什麼傳播者？」測驗

② 家族｜記憶與血緣的傳承層

語言若只停在個人，就容易斷裂；進入家族，才會成為可傳承的記憶。族譜不是資料表，而是文明延續的橋梁。

  • 建立族譜：串起祖先、長輩、家風與遷徙記憶
  • 保存照片、影片、音檔、故事與稱謂
  • 讓台語從「會說」變成「能被後代繼承」
建立咱兜族譜

③ 社團｜互助與文化擴散層

文明要持續，不只靠家庭，也需要組織。社團把零散熱情變成共同目標，讓文化能穩定擴散。

  • 社團任務：每週主題、挑戰、共同目標
  • 輔導員制度：資深帶新、代際陪伴、循環擴散
  • 治理儀表板：活躍度、達標率、排行與回饋
去看「本週台語傳播任務」

④ 友善場域｜語言回到公共生活

語言若不能被使用，就很難真正活著。友善場域讓台語重新進入市場、街道、店家與公共空間，成為文明運作的一部分。

  • 友善標章：申請、認領、分級
  • 推薦機制：會員 / 非會員權重、投票與見證
  • 曝光導流：榜單、地圖、活動串聯、生活使用

Regeneration Loop

再生循環：從家庭出發，走向城邦文明

家庭（日常說台語） → 家族（保存記憶與族譜） → 社團（形成互助組織） → 友善場域（進入公共生活） → 回饋（榮譽 / 內容 / 流量 / 新參與者） → 文明增長

循環如何啟動？

  • 用家庭共學，讓台語重新回到生活開口
  • 用族譜與家族記憶，讓語言跨世代延續
  • 用社團任務，把個人參與變成群體動員
  • 用友善場域，讓台語重新被社會看見與使用

循環如何變強？

  • 用勳章、榜單與榮譽牆，讓付出被看見
  • 用儀表板，讓治理成果被量化
  • 用故事、影音、記錄與推薦，持續沉澱內容資產
  • 讓每一個家庭與場域，都成為新的文明節點

12 個月落地路線

1

0–3 月｜家庭與家族播種期

核心家庭招募、族譜入口上線、家庭共學機制啟動，建立第一批家族故事與語言記錄。
2

4–8 月｜社團擴散期

社團任務、排行榜、輔導員制度上線，讓家庭與家族沉澱的內容轉化為穩定的社群動能。
3

9–12 月｜友善場域與聯盟期

友善標章、推薦地圖、跨區節點串聯，形成家庭、家族、社團、場域四層聯盟。

KPI（看得見的進步）

  • 家庭：日活、連續打卡、親子共學數
  • 家族：建立族譜數、故事上傳數、跨代參與數
  • 社團：活動數、帶新成功率、達標率
  • 場域：上架數、造訪數、推薦票數
  • 內容：音檔 / 短影音 / 情境句 / 家族記錄增長

資源配置（可調整）

  • 家庭 / 家族系統與內容：35%
  • 社團與活動：30%
  • 友善場域與傳播：25%
  • 治理儀表板與維運：10%
※ 預算與來源可依你們實際提案、募資、贊助或合作計畫調整。
